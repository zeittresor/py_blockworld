# py_blockworld
Creates a blockworld enviroment in Python to visit walking or to fly around in it..

Done by Vibecoding using GPT5.1 (Agent Mode).
(Using ~15 Prompts)

The Script will first of all create any required texture, skybox graphic, soundeffects and music/songs for it (but you can replace any file in the created data folder with your own).

If you have started the game you should be able to use WSAD controls, Space to jump, ESC for Menu, F12 for Screenshot (in the data\screenshots folder), Mouse to look / fly around (after entering Fly Mode using F Key) and you can use the left Mousebutton to remove a block in front of yourself.

btw. This is the first version of this - it works how it should - but there are still some minor glitches, you might notice (its work in progress).
